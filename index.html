공식 키보드 문서

다른 컴퓨터에서 작업하기

SSH 접속이 가능한 호스트에 Herdr와 필요한 에이전트 CLI를 준비합니다. 원격 쉘에서 작업 폴더로 이동해 herdr를 실행하면 그 컴퓨터에서 작업이 진행됩니다. 연결을 끊었다가 같은 호스트에 다시 접속해 세션을 이어갈 수 있습니다.

ssh 개발호스트
cd /path/to/project
herdr

로컬 Herdr 클라이언트로 직접 붙으려면 공식 문서의 herdr --remote 방식도 사용할 수 있습니다. 실행 전에 원격 호스트와 프로젝트 경로를 확인하세요.

공식 원격 작업 가이드

에이전트에게 작업 맡기기

Herdr 안에서 에이전트를 실행하면 사이드바에서 입력 대기와 작업 진행 상태를 확인할 수 있습니다. CLI로 세션을 제어할 때는 설치된 버전의 도움말과 공식 스킬을 참고하세요.

herdr pane list
herdr agent list
herdr agent --help

작업 지시에는 실행할 호스트, 저장소 경로, 변경 허용 범위, 검증 명령, 보고할 결과를 명시하세요.

문서만 수정하고, 실행한 확인 명령과 남은 제약을 보고해 주세요.

공식 Herdr 스킬

입력과 원격 연결이 막힐 때

  • 한글 조합 중 단축키가 반응하지 않으면 조합을 끝내거나 영문 입력 상태에서 다시 시도합니다. 마우스 메뉴로 같은 동작이 되는지도 확인합니다.
  • 키가 계속 반응하지 않으면 OS와 터미널 단축키가 같은 조합을 사용하는지 확인합니다.
  • 원격 연결이 끊겼다면 SSH 접속, 대상 프로젝트 경로, 실행 중인 Herdr 세션 순으로 확인합니다. 이전 패널 ID가 실패하면 목록을 다시 조회합니다.
