공식 키보드 문서

다른 컴퓨터에서 작업하기

원격 호스트에 Herdr와 에이전트 CLI를 설치합니다. SSH로 들어가 프로젝트 폴더에서 Herdr를 실행하세요. 같은 호스트에 다시 접속하면 세션을 이어갈 수 있습니다.

로컬 클라이언트에서 직접 연결하려면 herdr --remote 방식을 사용합니다. SSH 방식과 직접 연결 중 하나를 고르세요.

공식 원격 작업 가이드

에이전트에게 작업 맡기기

사이드바에서 진행 상태와 입력 대기를 확인하세요. CLI 명령은 설치된 버전의 도움말과 공식 스킬을 참고하세요.

작업 지시에 호스트와 저장소 경로, 수정 범위와 검증 기준을 적으세요.

패널이 완료로 표시되면 변경 내역과 검증 명령의 출력을 검토하세요.

공식 Herdr 스킬

에이전트에 붙이는 스킬 4가지

패널에서 에이전트를 돌릴 때 결과물의 완성도를 좌우하는 커뮤니티 스킬입니다. 설치 명령과 실전 프롬프트, 각 스킬이 하지 않는 일은 별도 정리 페이지에 있습니다.

Unslop
화면 점검보라 그라데이션, 글로우, 이모지 라벨, 과장 문구, 들쭉날쭉한 간격을 위치와 함께 짚고 고친 HTML을 만듭니다.이미 화면이 있을 때
UI UX Pro Max
디자인 방향제품 유형과 업종에 맞는 레이아웃·팔레트·글꼴 조합을 고르고, 피해야 할 패턴을 먼저 정합니다.구현 전
Diagram Design
구조 시각화아키텍처, 데이터 흐름, 시퀀스를 인라인 SVG가 든 HTML 한 장으로 그립니다. 화살표와 라벨이 겹치지 않게.구조를 설명할 때
Humanizer
문장 교정대비 강조, 극적 결론, 의미 부풀리기를 걷어냅니다. 사실과 숫자는 건드리지 않습니다.공개 문구 마무리

네 가지 모두 Anthropic 공식 기능이 아닌 커뮤니티 제작 스킬입니다. 설치 전에 저장소 코드와 요청 권한을 읽고, 결과물은 사람이 마지막에 확인하세요.

입력과 연결 문제 해결

  • 한글 조합 중 키가 반응하지 않으면 조합을 끝내거나 영문 입력으로 전환하세요.
  • 그래도 반응하지 않으면 OS와 터미널이 같은 키 조합을 사용하는지 확인하세요.
  • 원격 연결이 끊기면 SSH, 프로젝트 경로, Herdr 세션을 차례로 확인하세요. 패널 ID가 만료됐다면 목록을 다시 조회하세요.

이 페이지에 적용한 것

행 구분선과 코드 머리줄로 구조를 정리했습니다. 산화철 주황을 링크와 진행 표시 등에 적용했고, 7단계 흐름을 SVG로 그렸습니다. 모바일에서도 명령을 표시합니다. 언어는 한국어·중국어·일본어 세 가지이며, 라이트·다크 테마를 상단에서 바꿉니다.
