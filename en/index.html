Manage panes with the keyboard

The default prefix is Ctrl+B. Press and release it, then press an action key.

Work on another computer

Install Herdr and the agent CLI on the remote host. Connect over SSH and start Herdr in the project directory. Reconnect to the same host to resume the session.

To attach from your local client, use herdr --remote. Choose either SSH or direct attachment.

Hand off a task

Check progress and requests for input in the sidebar. For CLI operations, consult the installed version’s help and the official skill.

Give the agent the host, repository path, allowed changes, and verification criteria.

When the pane reports completion, inspect the diff and output from the checks.

Fix input and connection issues

  • If the input method is composing text, finish composition or switch to direct input.
  • If a shortcut still fails, check whether the OS or terminal intercepts that key combination.
  • After a disconnect, check SSH, the project path, and the Herdr session. If a pane ID is stale, list the panes again.
